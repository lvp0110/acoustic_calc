# Acoustic Calculator

Веб-приложение для расчета акустических материалов с выбором бренда, модели и опций.

## 🚀 Возможности

- **Выбор бренда и модели** акустических материалов
- **Настройка опций**: размеры, цвета, перфорация, кромки
- **Калькулятор** для расчета материалов по размерам или площади
- **Адаптивный дизайн** с поддержкой различных разрешений экрана
- **Экспорт результатов** в Excel
- **Таблица результатов** с детальной информацией о расчете

## 📋 Требования

- Node.js 20 или выше
- npm или yarn

## 🛠️ Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/lvp0110/acoustic_calc.git
cd acoustic_calc
```

2. Установите зависимости:
```bash
npm install
```

## 🏃 Запуск проекта

### Режим разработки

1. Убедитесь, что у вас установлен Node.js 20 или выше:
```bash
node --version
```

2. Установите зависимости (если еще не установлены):
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

Приложение автоматически откроется в браузере по адресу `http://localhost:5173`

**Важно для локальной разработки:**
- API запросы будут проксироваться на `http://localhost:3005` через Vite proxy
- Убедитесь, что ваш backend API сервер запущен на порту 3005
- Если API на другом порту, измените настройки proxy в `vite.config.js`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist`

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

## 🎨 Особенности интерфейса

- **Адаптивная верстка**: при разрешении более 1024px таблица результатов отображается справа от блоков выбора
- **Интуитивный выбор**: поддержка выбора с изображениями и текстовых селектов
- **Валидация данных**: проверка корректности введенных размеров и площади
- **Автоматический расчет**: автоматический расчет площади при вводе размеров

## 🌐 Деплой

Production frontend запускается в Docker на `prodfront` и доступен только во
внутренней сети на порту `3010`. Публичный HTTPS завершается на `gateway-01`.
Адрес приложения: `https://acousticcalc.constrtodo.ru`.

Браузер обращается к same-origin пути `/api`. Node-сервер frontend проксирует
эти запросы на внутренний ConstrTodo backend, заданный переменной `BASE_URL` в
серверном `.env.prod`.

Первоначальное разворачивание:

```bash
cp deploy/.env.deploy.example deploy/.env.deploy
# заполнить deploy/.env.deploy
make deploy-bootstrap
```

Последующие ручные обновления:

```bash
make deploy-frontend
make deploy-status
```

После слияния инфраструктурной ветки в `main` деплой запускается автоматически
через GitHub Actions. Подробности находятся в `deploy/README.md`.

### Локальная разработка

Для локальной разработки создайте файл `.env.local` (он уже в `.gitignore`):

```bash
VITE_API_URL=http://localhost:3005
```

Или просто используйте значение по умолчанию - `http://localhost:3005`.
